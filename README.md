# 📱 دفتر گفتگو (Conversation Journal)

> **An AI-powered conversation journaling app to record, manage, and always remember your interactions with others.**  
> این اپلیکیشن برای ثبت گفتگوهای شما با افراد مختلف طراحی شده و متصل به هوش مصنوعی است تا بتوانید مکالمات خود را ذخیره کرده و همیشه جزئیات آن‌ها را به یاد داشته باشید.

---

## ✨ امکانات و قابلیت‌ها (Features)

- 💬 **رابط کاربری مدرن به سبک تلگرام (Telegram Native UI):** چیدمان روان، طراحی تمیز چت‌ها و لیست مخاطبین همراه با انیمیشن‌های نیتیو.
- 🤖 **دستیار هوش مصنوعی یکپارچه (AI Integration):** تحلیل، خلاصه‌سازی و پردازش گفتگوها با اتصال به مدل‌های زبانی هوش مصنوعی.
- 📝 **ثبت دوگانه یادداشت‌ها:** تفکیک موضوعات مکالمه (حباب‌های سفید) و یادداشت‌های محرمانه/تحلیلی (حباب‌های زرد/طلایی).
- 🖼️ **شخصی‌سازی پیشرفته:** گالری پس‌زمینه‌های طبیعی برای چت‌ها به همراه ابزار کراپ دایره‌ای عکس پروفایل.
- 🔐 **احراز هویت مستقل و ماژولار:** صفحات مجزا برای ورود، ثبت‌نام با تایید پیامکی و بازیابی رمز عبور.
- 👑 **پنل مدیریت و ادمین (Admin Panel):** پایش مالی و هزینه دلاری، مدیریت فیش‌ها و اشتراک‌ها، تنظیمات مدل‌های هوش مصنوعی و بنرهای سیستمی.

---

## 🛠️ تکنولوژی‌ها (Tech Stack)

- **Frontend Framework:** Next.js (Static Export `out`)
- **Mobile Container:** Capacitor (Android)
- **Styling:** Tailwind CSS (Telegram Dark / Light Theme)
- **Icons & Assets:** FontAwesome / Heroicons
- **AI Core:** Google Gemini API / OpenAI Compatible Endpoints
